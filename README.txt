Комплект для GitHub Copilot coding agent.

Порядок:
1. Распаковать содержимое в корень репозитория `archive-mvp`.
2. Передать Copilot `prompts/01_audit.md`.
3. После аудита передать `prompts/02_implementation.md`.
4. После успешных тестов передать `prompts/03_security_audit.md`.
5. Для подготовки VPS передать `prompts/04_deploy_preparation.md`.

Реальные токены, ключи и `.env` в архив не включены.
