# AGENTS.md

## Назначение
Минимальный MVP системы «Архив Терпения»: Telegram принимает материалы, LLM обрабатывает их, результат сохраняется как русскоязычная Markdown-карточка.

## Правила
1. Сначала изучи существующий код.
2. Не переписывай проект целиком без необходимости.
3. Не добавляй Docker, Redis, PostgreSQL, Celery, Kubernetes, embeddings или vector database на первом этапе.
4. Не изменяй и не выводи реальные секреты.
5. Не создавай настоящий `.env`; создай только `.env.example`.
6. Не удаляй рабочие функции без объяснения.
7. Все новые функции должны обрабатывать ошибки.
8. Исходный код не должен содержать эмодзи.
9. Не добавляй автономную публикацию без отдельного подтверждения.
10. Не меняй VPS, SSH, firewall или systemd без отдельного согласования.
11. Не считай задачу завершенной без проверок.

## Разделы архива
1. Фреймворки промптов
2. Инструменты
3. Системы и схемы
4. Устарело / Потеряло силу
5. На рассмотрении

## Карточка
- Раздел
- Название
- Тип
- Суть
- Как использовать
- Когда особенно полезно
- Нюансы и ограничения
- Оценка полезности
- Вердикт

## Обработка
Не упоминать авторов, никнеймы, даты публикации, Twitter или X и элементы интерфейса. Не копировать текст дословно. Переводить и перерабатывать на русском языке. Независимые идеи разделять на отдельные карточки. Недостаточно надежные материалы помещать в «На рассмотрении».

## Каталоги
- `storage/inbox/` — исходные материалы
- `storage/archive/` — готовые карточки
- `storage/review/` — материалы для проверки
- `logs/` — журналы
- `tests/` — тесты

Исходные материалы не удалять.

## Готовность
Проверить синтаксис, импорты, тесты, отсутствие секретов в Git, запуск без ключей и обработку невалидного ответа LLM.

В отчете указать: выполнено, проверки, измененные файлы, риски и один следующий шаг.
