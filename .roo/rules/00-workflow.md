# Roo Workflow

## Перед началом любой задачи

1. Прочитай AGENTS.md.
2. Прочитай релевантные правила .roo/rules/.
3. Посмотри git status.
4. Найди существующий код.
5. Не создавай новые файлы автоматически, если существующий файл подходит.

---

## Если задача большая

Раздели её на этапы.

Не реализуй всё одним изменением.

Формат:

PLAN
↓
IMPLEMENT
↓
TEST
↓
REPORT
↓
NEXT

---

## Если найдено несколько решений

Предложи:

A — минимальное
B — более сложное
C — будущее

По умолчанию использовать A.

---

## Если что-то не работает

Не скрывай ошибку.

Покажи:

SYMPTOM
CAUSE
FIX
TEST

---

## Если неизвестно

Не угадывай.

Используй:

UNKNOWN

и укажи, что нужно проверить.

---

## Если требуется новая библиотека

Перед установкой:

1. объясни зачем;
2. проверь существующие зависимости;
3. проверь standard library;
4. оцени размер/нагрузку;
5. только потом устанавливай.

---

## Если требуется изменение архитектуры

Остановись.

Сначала сообщи:

CURRENT
PROPOSED
WHY
BENEFIT
RISK
COST

И запроси подтверждение.

---

## После каждого этапа

Покажи:

STATUS: DONE / BLOCKED

FILES:
...

TESTS:
...

RESULT:
...

RISKS:
...

NEXT:
...
