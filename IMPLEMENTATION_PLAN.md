# План реализации MVP

## Цель
Создать надежный Telegram-бот, который принимает материалы, обрабатывает их через OpenRouter и сохраняет структурированные Markdown-карточки.

## Этапы
1. Аудит существующего проекта.
2. Конфигурация через переменные окружения.
3. Telegram: `/start`, `/help`, текст, изображения, документы.
4. Сохранение исходных материалов.
5. Отдельный LLM-клиент.
6. Валидация JSON-ответа.
7. Сохранение валидных карточек в `storage/archive/`.
8. Сохранение проблемных материалов в `storage/review/`.
9. Логирование и обработка ошибок.
10. Тесты и README.
11. Подготовка инструкции ручного деплоя.

## Не делать на первом этапе
Docker, Redis, PostgreSQL, Celery, Kubernetes, embeddings, vector database, сложную multi-agent систему, веб-интерфейс, платежи и автономную публикацию.

## Критерии приемки
- `/start` отвечает;
- текст принимается;
- изображения и документы сохраняются;
- LLM вызывается через отдельный модуль;
- валидная карточка сохраняется;
- невалидный ответ попадает в review;
- ошибки записываются;
- тесты проходят;
- секреты не попали в Git;
- README позволяет повторить запуск.
